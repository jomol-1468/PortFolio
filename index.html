LET ME INTRODUCE MYSELF

I fell in love with the moment an API call actually returns what it's supposed to — and I've been chasing that feeling since my first Django CRUD app. These days it's less "does it run" and more "does it scale, stay secure, and not fall over at 2am." 🧑‍💻

I'm fluent in the languages that do the heavy lifting — Python, Java, JavaScript, TypeScript, HTML5, and CSS3 — and I reach for whichever one actually fits the problem instead of forcing a favorite.

On the frontend, I build interfaces in React.js and Next.js, styled with Tailwind CSS and Bootstrap, that stay responsive without feeling like an afterthought. On the backend, I ship REST APIs with Django, Django REST Framework, Flask, FastAPI, Node.js, and Express.js, backed by MongoDB, MySQL, PostgreSQL, or SQLite depending on what the data actually needs.

Everything ships through Git and GitHub, gets tested with Postman and Jest, and increasingly runs alongside AI-powered backends — I'm actively growing into NLP and deep-learning models, because that's where full-stack development is heading, and I'd rather build with it early than catch up later.
